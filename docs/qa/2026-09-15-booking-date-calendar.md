# QA — 예약 Step 2 예약 가능일 캘린더 (2026-09-15)

## 변경 요약
- Step 2의 `검사 예정일` date input을 월간 가용성 캘린더(`BookingDatePicker`)로 교체했습니다.
- 달력 셀은 `가능 N`, `마감`, `휴진`, `단축` 상태를 표시합니다. 셀 title에는 위·대장 수용 현황과 가능 시간이 들어갑니다.
- 달력 아래에 다음 가능일 3개를 칩으로 둡니다. 날짜를 선택하면 가능한 첫 시간이 자동으로 선택됩니다.
- `scheduler.ts`에 일정 규칙만 검증하는 `validateSchedule`, 날짜별 가용성을 계산하는 `dayAvailability`, 일요일 휴진 규칙을 추가했습니다.
- 슬롯 버튼과 대안 시간은 일정 규칙만 기준으로 판단합니다. 폼 오류(환자정보, 복용약, 예외 사유)는 `validateBooking`에서 계속 저장을 막습니다.
- 선택 가능 기간은 `REFERENCE_TODAY`부터 3개월 뒤의 월말까지입니다. 기존 하드코딩 min/max는 제거했습니다.
