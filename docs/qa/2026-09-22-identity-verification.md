## QA 중 발견해 고친 문제

모두 이번 Sprint 화면 코드의 결함이며 커밋 전에 고쳤다.

1. 실제 예약 주간 카드에 연결하지 않은 약제·D-1·예약금 표시가 나왔다. 실제 예약
   카드에는 이중확인 표시만 남겼다.
2. 일간 보드의 실제 예약 행에 PACS 상태가 보였다. 실제 예약에서는 숨겼다.
3. 실제 예약 상세 메모의 기본 문구가 확인 업무를 Prototype으로 안내했다. 이중확인이
   Backend에 연결됐다는 문구로 바꿨다.
4. 확인 업무 표의 `확인 열기`가 두 줄로 꺾였다. 줄바꿈을 막았다.
5. 주간 보드 왼쪽 `오늘 우선 처리`가 합성 Fixture(가짜 이중확인 3건과 약제·D-1·예약금
   대기)를 실제 일정 옆에 보여 줬다. 확인 업무 화면과 같은 실제 이중확인 대기로 바꾸고,
   미연결 업무는 안내 문구만 두고, `모든 확인 업무 보기`를 확인 업무 화면에 연결했다.
6. 1366 폭에서 위 카드에 날짜를 넣자 환자 이름이 잘렸다. 날짜와 상태를 따로 한 줄로
   옮겼다.
7. 권한이 없는 계정은 확인 버튼만 사라지고 이유가 보이지 않았다. 단계별 권한 안내를
   더하고, 확인 Panel 안의 안내 글자를 본문 크기로 키웠다.
8. 예약 상세 업무 요약이 실제 예약에도 장정결제·본인부담 `해당 없음`, 일반검진·
   대장암검진 `미확인` 같은 Prototype 기본값을 보여 줬다. 실제 예약은 저장된 값과
   메모만 보여 주고, 환자·검사 탭의 국가검진 편집기에는 Prototype 기본값이라는 안내를
   더했다.
9. 일간 보드 오른쪽 안내 Panel 제목이 `PACS 입력 확인 Panel`이었다. PACS 확인은 아직
   없으므로 `인적사항 이중확인`으로 바꾸고, 실제 동작(예약을 눌러 상세에서 1·2차 확인)을
   설명하게 했다.
10. 일간 보드의 실제 예약 행이 재확인 필요도 `대기`로만 보였다. 재확인 필요·1차 확인
    대기·2차 확인 대기·이중확인 완료를 구분해 보여 준다.
